# 人生无限可能 · Life Simulator

> 如果人生可以重来，你会怎么选？

《人生无限可能》是一款选择驱动的现代都市人生模拟 H5 游戏。玩家创建一位年轻主角，在 12 个季度里平衡职业、创业、现金流、精力、压力、幸福与关系。

## 第一阶段已经实现

- 六位原创预设主角与大图预览
- 普通、经济宽裕、负债三种家庭背景
- 财富自由、事业成功、幸福生活三种人生目标
- 手机、平板、电脑自适应布局
- 工作、学习、副业、人脉、休息、创业六种季度行动
- 三个人生测试事件与完整的行动 → 事件 → 选择 → 结算流程
- 带种子的随机数、统一数值结算和延迟后果
- 12 季度循环与五种人生结局
- 浏览器本地自动存档、继续游戏和安全重开
- GitHub Pages 自动部署工作流

第一版不使用后端、账号系统或付费 AI API。

## 本地运行

```bash
npm install
npm run dev
```

质量检查：

```bash
npm run typecheck
npm test
npm run build
```

## 项目结构

```text
src/engine/      纯规则引擎、结算与带种子随机数
src/data/        角色、背景、目标、行动、事件与结局配置
src/storage/     带版本号的 localStorage 存档
src/ui/          首页、人物创建、主游戏与结局界面
src/components/  通用视觉组件
public/assets/   原创人物立绘与场景背景
tests/           引擎与存档测试
```

## 美术说明

当前六位主角和五个场景是为原型生成的原创基础素材，已经拆分为独立文件并接入统一素材配置。正式发布前仍建议进行人工美术审校，尤其检查角色手部、服装细节与全套表情/换装的一致性。NPC 独立立绘、人物表情差分和三套服装是第二阶段内容。

## 部署

仓库推送到 `main` 后，`.github/workflows/deploy.yml` 会执行测试、构建并发布 GitHub Pages。Vite 的公开路径已配置为 `/life-simulator-game/`。
